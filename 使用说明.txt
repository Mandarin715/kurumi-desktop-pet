久留美桌宠
==========
双击 Kurumi.exe 即可运行，无需 Python。普通互动、截图识别无需联网。
欧易 OKX 公共行情需联网，无需 API Key；账户读取为可选功能。

普通模式：左键随机换图说台词，4 秒回默认；按住拖动，记住位置。
右键角色或托盘：FX启动！、行情数据源、FX设置…、静音、桌宠大小、开机自启、退出。
保留 1024 像素原图适配高 DPI，提供三种大小、切图与气泡动画。
设置和提示窗口打开时自动避开桌宠，优先在同屏空位显示；无需先拖走窗口。

FX启动！
--------
1. 默认使用“截图识别”。每次勾选“FX启动！”都先框选一个完整价格数字，稍留边距，不含代码、涨跌幅或其他价格。
   Esc / 右键取消后 FX 保持关闭，不沿用旧区域。开启 FX 时手动切到截图数据源也会重新框选。
2. 默认每 3 秒只截图该区域，用附带 RapidOCR 本地模型识别。
   两种预处理都高置信度读到相同价格才接收；读不清则跳过，不猜测。
   遮挡只判断真实角色像素和可见气泡，透明窗口留白不算遮挡；多屏与缩放统一用逻辑坐标。
3. 至少积累 10 秒、4 个有效价格后，按实际跨度先判断普通心情，不推算涨幅。
   30 秒短窗口主导表情；完整短窗口后才启用大涨 / 大跌。
   进入阈值：≥ +0.30% 用 1、5；≥ +0.08% 用 2；中间横盘用 6；
   ≤ -0.08% 用 11、7；≤ -0.30% 用 3、9。
   完整 120 秒长窗口用于风险保护和情绪确认，不阻止短窗口反向表情。
   短或长窗口跌超过 3%，或跌破止损价：13、8、14，可立即提醒。
   退出阈值更低：普通涨跌回横盘为 ±0.04%，大涨跌回普通为 ±0.20%。
   普通心情变化需连续 2 次有效采样确认，防止边界反复跳。
   两个窗口取最接近目标时间的真实采样，允许半个采样间隔的毫秒抖动。
   成功读价间隔超过 30 秒会重建窗口，同 API 品种内部失败恢复可保留。
4. 普通自动换脸至少保持 10 秒，普通幅度突变不跳过保持时间。
   首次恐慌、跌破止损、新账户风险可立即切换；相同心情不轮播。
   只有实际换表情才说普通台词和播放音效，气泡消失不重置 FX 表情。
   点击可立即在当前心情图片池换图并重启保持；单图池不重复说话。
   初始数据不足时不猜测心情。
5. 同方向心情持续 20 秒满情绪，且完整 120 秒长窗口同向超过 0.04% 后，
   才使用第二档台词。反向 / 横盘重计，不因采样更快而累积更快。
6. FX设置…中填写止损价；留空关闭。跌破时喊“该止损了……真的要止损吗？”。
   回到止损价上方后再次跌破才会再提醒。
7. 满 1 小时会用第 4 张提醒“休息一下吧”，每次 FX 会话一次。
8. 取消勾选后回默认图，总结今天首次 / 最后一次读价之间涨跌多少。
   这是盯盘记录，不是交易所当天涨跌幅。截图每次框选会重置区域基准，OKX 同品种当天仍沿用基准。

行情窗口移动、缩放或切换股票后，请关闭再开启 FX 重新框选，会重置当天基准。
设置中不再提供单独的“重新框选”按钮。
数值输入框不接受滚轮改值，滚轮用于滚动页面；仍可键盘输入或点击上下箭头。
“恢复数值默认”恢复默认灵敏度、两条 3% 账户提醒线并清空手填止损价，保存后生效。
交易对、模拟盘选项和密钥不受恢复默认影响；取消设置则放弃本次修改。
请保持数字清晰可见；遮挡、特殊字体、小数点不清可能导致跳过或误读。
右键菜单与托盘提示可查看最近读价、涨跌幅、心情和情绪值。

欧易 OKX 数据源
---------------
右键“行情数据源”→“欧易 OKX API”，在“FX设置…”先选现货或永续，再搜索 / 选择交易对。
例如 BTC-USDT；永续自动追加 -SWAP，不会重复追加。公共列表后台加载，缓存一小时，
可点击刷新；加载失败可用缓存或手动输入完整交易对，无需 API Key。
截图模式下交易对选择禁用，照旧读取屏幕框选价格。
再打开 FX，默认每 2 秒调度公共行情，沿用上面的双窗口、10 秒保持及防抖规则。
数据源选择保存到 exe 旁 kurumi.json，下次直接使用。

表情灵敏度可选外汇股票（0.05 / 0.20 / 2%）、默认（0.08 / 0.30 / 3%）、
加密货币（0.15 / 0.60 / 5%）或自定义，依次为横盘、强波动、恐慌跌幅。
自定义显示三个百分比输入框，最多两位小数，省略末尾多余的零（如 0.08 %、0.3 %）。
输入和保存精度为两位，必须为正数且严格递增，不合法不能保存。
恢复默认只恢复灵敏度，不影响交易对和密钥。退出阈值自动按比例计算。
保存立即生效，保留价格窗口；清掉旧阈值下的连续确认计数，普通心情需重新确认两次。
30 / 120 秒窗口、采样间隔和保持时间不变；账户亏损提醒线独立设置。
更换交易对或现货 / 永续、模拟盘 / 实盘会清空价格窗口重新预热，保留休息计时。
手填的绝对止损价会清空并提示，请按新品种重设；账户百分比提醒线保留。

账户独立每 5 秒调度，慢账户请求不拖慢行情。未完成的请求不会堆积，
因此网络较慢时实际采样间隔会延长。账户失败不触发行情回退。
账户读取可选：在设置中填写 API Key、Secret Key、Passphrase，使用只读权限。
含交易或提币权限会提醒“建议改成只读”，禁用账户读取，公共行情可继续使用。
模拟盘需勾选“模拟盘”，并填写对应模拟盘密钥。
任一非零持仓的接口浮亏率达到 3% 时提醒“该止损了……真的要止损吗？”。
启用账户读取后以账户浮亏率替代手填止损价。
账户权益较 UTC+8 当天首次观测下降达到 3%，会哭泣并劝今天停手，每天提醒一次。
这个比例是“本程序今日观测值”，不是交易所完整当日盈亏；转入转出也会影响。
首次观测之前的盈亏不计入，基准跨重启保存，模拟盘和实盘分开。
两个阈值都可在设置中调整，或修改 JSON 中 okx.position_stop_loss_percent /
okx.daily_loss_percent，默认均为 3，单位是百分数。

连续读取失败 3 次才说“欸？行情连不上了……”，回退截图识别；成功后失败计数归零。
回退后每 30 秒重试 OKX，成功自动切回；没有价格区域也继续重试。
单次请求至少允许 5 秒，旧 JSON 中更短的超时值在运行时按 5 秒处理，不改写文件。
无有效价格区域时可在 FX设置 框选同一品种的价格。
截图与 API 互切一律清空窗口，重新满足 10 秒及 4 个有效价格的预热条件，包括菜单切源、失败回退和自动恢复。
只有 API 同一交易对、同一实盘 / 模拟盘内的重试或重连才保留历史。
修改交易对或实盘 / 模拟盘也清空窗口；切源仍保留表情保持及休息计时。
JSON 仍保留首选 OKX；主动选截图后停止 API 重试。
当天价格统计按截图区域、OKX 交易对和模拟盘 / 实盘分别保存。
同一截图区域的价格较当天基准或上次价格偏离超过 50%，会重置基准和价格窗口。
直接改 fx/region 也按新区域统计；每次开启截图 FX 时的框选会清空旧、新区域当天基准。

隐私
----
截图只在本地内存处理，不保存、不上传，不调用云端模型，不下载模型。
保存价格区域、止损价、桌宠位置、大小、静音偏好、当天首尾有效价格与观测权益基准。
密钥仅存在 exe 旁 okx.local.json，不写日志、不传给模型、不打包到 exe。
账户认证仅通过 HTTPS 发往 OKX；该文件是本机明文配置，请勿随程序分享。
要移除凭据，在设置中清空三项并保存。程序没有下单、撤单、提币接口。
菜单 / 设置打开时暂停采样；FX 默认关闭，每次打开程序需主动勾选。

换图、改台词和阈值
------------------
exe 旁 assets\kurumi_01.png ～ kurumi_14.png：透明素材；kurumi.json：台词和规则。
缺失或损坏的外置素材逐张回退内置。也可只复制一个 exe 使用。
JSON 顶层 lines 是普通台词，fx.lines_intense 是高情绪台词，fx.poses 是图片池。
fx.interval_ms / okx_interval_ms / account_interval_ms：3000 / 2000 / 5000，毫秒。
fx.fast_window_seconds / window_seconds：30 / 120，秒；fx.hold_seconds：10。
fx.warmup_seconds / warmup_samples / confirm_samples：10 / 4 / 2。
fx.flat_percent / strong_percent / panic_drop_percent：0.08 / 0.30 / 3，百分数。
fx.flat_exit_percent / strong_exit_percent：0.04 / 0.20，百分数。
fx.emotion_seconds：20；fx.flat_sleep_seconds：300；fx.rest_after_seconds：3600。
fx.ocr_confidence：0.90；max_sample_gap_seconds：30。
旧字段 emotion_streak、immediate_change_percent 不再参与新逻辑。
fx.stop_loss 是初始止损价，设置窗口里保存的个人值优先。其他字段详见源码 README.md。
修改 JSON 后退出重启生效，保持 UTF-8 编码和合法 JSON 格式。
图片来自原始白底 JPG 本地抠图；更高清的细节需替换为更好的原始透明图。

自启和存储
----------
自启仅当前用户，无需管理员。exe 移位后取消并重新勾选自启来更新路径。
设置：HKCU\Software\KurumiPet\DesktopPet。
日志：%LOCALAPPDATA%\KurumiPet\kurumi.log；日志不含截图或 OCR 原始文本。

远程测试开关（保留现有配置）
--------------------------
在 kurumi.json 已有的 fx 对象内添加以下两项，不要另建第二个 fx 或覆盖其他值：
  "exclude_from_capture": false,
  "debug_log": true
保存后退出重启。未填写时，exclude_from_capture 默认 true，debug_log 默认 false。
false 允许远程截图看到桌宠；true 保持从截图中排除的行为。
如果桌宠挡住价格区域，该次 OCR 仍跳过，请将她拖开。

debug_log 开启后，kurumi.log 中以 FX_DEBUG 标记每次成功采样或跳过：
时间（含毫秒 / 时区）、采样开始时间、处理耗时、价格、短 / 长窗口涨跌幅、
实际跨度 span_seconds、短窗口未满 warming、心情、
台词情绪档、是否跳过及原因。未读到价格 / 短预热未满足时 percent 为 null，长窗口未满时 long_percent 为 null。
每次实际换图另记图片编号、音效分组和具体名称。
音效异步处理，queued 表示排队、尚未确认播放；随后 audio_result 用相同
pose_id 记录 played 成功或 cancelled / failed / closed，不把排队当播放成功。
静音 muted、零音量 volume_zero、无对应音效 no_effect 直接记为未播放。
通过 sample_time / monotonic_s 可查看真实采样间隔，通过 time 查看换图时间。
日志不记录截图、OCR 原文、密钥、认证头或账户接口原始响应。
关闭 debug_log 后停止这些诊断行，保留原有警告 / 错误日志。
完整字段及跳过原因对照见 README.md“远程测试与采样日志”。

音效
----
普通模式点击换表情：click_1.mp3。
FX 换到上涨表情：good_1 / good_2 随机；换到下跌表情：bad_1 / bad_2 / bad_3 随机。
只在真的换脸时响，未换脸的轮询不响；横盘、休息等其他表情无音效。
音效在后台打开和播放，连续点击只保留最新请求，减少点击和双击时的卡顿。
新音效打断上一段，避免叠音；右键“静音”停止播放并取消排队音效，记住下次启动。
kurumi.json 中 sound.volume 为 0～1 的音量，默认 0.6；0 无声，1 最大，改后重启。
例如："sound": {"volume": 0.3}。只调整桌宠音量，不改变 Windows 系统音量。
只用了提供素材 mp3/ 中上述六个同名文件，未使用其他音效。
外置 assets\sfx\ 同名 MP3 优先，缺失或无法解码时回退 exe 内置版本。
LICENSES.txt 原样附在项目与发布目录，exe 内也有一份。

源码构建：powershell -ExecutionPolicy Bypass -File build.ps1
