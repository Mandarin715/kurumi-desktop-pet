## 介绍

把《FX战士久留美》里的久留美带到你的桌面：平时是能点击、能拖动的小伙伴，开启「FX启动！」后，她会根据价格变化换表情、说台词。截图识别和 OKX 行情二选一，按自己的习惯来。

## 功能亮点

| | 久留美能做什么 |
| :--- | :--- |
| 🌸 桌面陪伴 | 14 种表情、气泡台词与柔和切换动画；拖到喜欢的位置，下次还在。 |
| 📈 FX启动！ | 本地截图识别价格，或连接 OKX 公共行情；支持现货、永续和 XPERP。 |
| 🎚️ 按你喜好 | 表情灵敏度、音效音量、静音和桌宠大小都能调整；图片、台词也能自己换。 |
| 🔔 贴心提醒 | 可设置止损提醒，盯盘满一小时提醒休息；账户读取按需开启。 |
| ✨ 自动更新 | 启动时检查新版，可更新、稍后或跳过；自动更新保留个人配置与素材。 |

截图只在本地内存中处理，不保存、不上传。OKX 公共行情无需密钥，账户功能可选；程序只读数据，不进行交易。

## 快速上手

1. **解压并打开**：把完整压缩包解压到一个文件夹，双击 `Kurumi.exe`。
2. **先和她打个招呼**：左键点击换表情，按住拖动；右键打开菜单，调整大小、静音或退出。
3. **想让她陪你盯盘**：右键选择「行情数据源」，再开启「FX启动！」。截图模式每次开启都需框选**一个完整价格数字**；OKX 模式先在「FX设置」里选择市场类型和交易对。
4. **调成喜欢的样子**：在「FX设置」里调整灵敏度与音量。完整包附有最新版图文教程，遇到问题可以先翻一翻。
