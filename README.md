# 久留美桌宠

Python + PySide6 编写，PyInstaller 单文件 exe，Windows 10/11 64 位。
从 [Releases 下载 Windows 完整包](https://github.com/Mandarin715/kurumi-desktop-pet/releases/latest)，解压后双击 `Kurumi.exe`，无需 Python。
图文教程：[久留美桌宠使用教程（Word）](docs/久留美桌宠-使用教程.docx)；文字说明：[使用说明](使用说明.txt)。完整包内也附有两份说明。
普通互动和截图识别无需联网；OKX 公共行情需联网，无需 API Key。发布包使用默认配置，不含个人 API 密钥或 `okx.local.json`。

## 自动更新（v1.2.0 起）

exe 启动约 3 秒后在后台检查本仓库最新正式 GitHub Release；只提示高于当前版本的正式版本。断网、检查超时或发布信息无效时静默跳过。旧版首次升级需手动安装带更新功能的版本。

粉色提示窗会显示版本号和 Release 说明，提供“更新”“百度网盘”“夸克网盘”“稍后”“跳过此版本”。稍后可在下次启动时再次提示；跳过记录保存在本地 QSettings，只跳过所选版本，未来更高版本仍可提示。网盘按钮用默认浏览器打开固定链接：[百度网盘（g64g）](https://pan.baidu.com/s/1Fuasa1-ZIbr1AAknZswXqA?pwd=g64g)、[夸克网盘](https://pan.quark.cn/s/3d36119ca037)；请自行核对网盘里的文件版本。

“更新”从 GitHub 直连下载，显示进度；连续 20 秒无数据，或下载 30 秒后平均速度低于 100 KiB/s 时，原窗口提示改用网盘，也可继续等待或取消。下载失败同样在原窗口提示，不另弹报错。只有文件大小、SHA-256 和更新包文件清单全部校验通过，才启动本地助手退出桌宠、替换并重启；新版未正常启动会恢复旧程序。受系统保护的只读目录可能需要改用手动更新。

自动替换仅限 `Kurumi.exe`、README、文字说明、许可证和使用教程。`kurumi.json`、`okx.local.json`、外置自定义素材和本地位置 / FX 设置保持不变。更新检查和下载只使用公共 GitHub 请求，不读取或发送 OKX 密钥。Release 说明作为纯文本显示，不加载其中的远程图片或脚本。

维护者运行 `release_package.py` 生成 `dist/Kurumi-v1.2.0-Windows-x64.zip`、`SHA256SUMS.txt` 和对应 Release 说明文件；上传同版压缩包和校验文件并填写 Release 说明，即可供后续客户端检查。公开包从默认值生成配置，使用 `dist` 中最新 Word 教程，不读取或包含个人密钥文件。源码运行与自检模式不自动检查更新。

## 桌面互动

- 透明、置顶、无边框，无任务栏按钮，透明区域可穿透点击。
- 默认第 10 张；普通模式点击不重复随机切图，说对应台词，4 秒恢复默认。
- 拖动并保存位置；右键和托盘提供 FX、自启、大小、退出；FX 设置的音效音量滑块可即时调节。
- 设置和提示窗口初始避开桌宠与气泡，优先使用同屏空位；多屏时可选其他屏幕，空间不足时调整可滚动窗口尺寸。打开窗口时桌宠的拖动规则不变。
- 原始 1024px 素材按实际 DPI 渲染，260/340/420 三种大小；切图 280ms 淡入淡出、轻微上浮，气泡 190ms 动画。
- exe 旁 `assets/kurumi_01.png`～`kurumi_14.png` 逐张覆盖内置素材。`kurumi.json` 可外置，也支持 `assets/kurumi.json`，前者优先。损坏或缺失时回退内置。

## FX启动！

默认关闭。右键“行情数据源”选择“截图识别”或“欧易 OKX API”，选择保存到 exe 旁的 `kurumi.json`。

截图模式每次勾选“FX启动！”都先拖动框选屏幕上**一个完整价格数字**，稍留边距，不含代码、涨跌幅或其他价格。Esc / 右键取消后 FX 保持关闭，不沿用旧区域。开启 FX 时手动切到截图数据源也会重新框选；行情窗口移动、缩放或切换股票后，请关闭再开启 FX。设置中不再提供单独的重新框选按钮。

默认每 3 秒只截这块区域，在后台用 RapidOCR 的 PP-OCRv4 本地 ONNX 识别模型读数字。原图和灰度对比增强两次识别必须都是单个正数、置信度至少 0.90 且结果一致，否则跳过，不更改价格历史或情绪。没有数字纠错或猜测补值。支持小数点、规范千分位及常见货币符号；框选要贴合一行价格。至少积累 10 秒跨度、4 个有效价格后，用已有跨度先判断普通涨跌和横盘，不按比例推算成 30 秒涨幅；读不到数字不计数。短窗口满约 30 秒后才启用大涨 / 大跌表情，长窗口满约 120 秒后参与风险保护和高情绪台词。

关闭截图排除，或系统无法排除桌宠时，遮挡检查只计算实际角色像素和可见气泡，包括切图时尚未淡出的上一张。透明窗口边框、头顶留白和 PNG 透明区域不会阻止读取；多屏和缩放统一使用逻辑坐标。开启调试日志后，真正遮挡的记录附带价格区域、桌宠原点和可见区域边界，便于核对。

| 最近约 30 秒涨跌幅（进入阈值） | 姿势 |
| --- | --- |
| ≥ +0.30% | 1、5 |
| ≥ +0.08% 且 < +0.30% | 2 |
| -0.08% < 幅度 < +0.08% | 6，连续横盘 5 分钟换 4 |
| ≤ -0.08% 且 > -0.30% | 11、7 |
| ≤ -0.30% | 3、9 |
| 短窗口或长窗口 < -3%，或严格低于止损价 | 13、8、14 |

短窗口主导普通心情，长窗口上涨不会阻止近期下跌表情。普通心情变化需要连续 2 次有效采样确认；上涨 / 下跌退回横盘的阈值为 ±0.04%，大涨 / 大跌退回普通涨跌的阈值为 ±0.20%，减少边界附近反复切换。采样失败不猜测、不补价格。

两个窗口都选择最接近目标时间的真实采样，不插值；完整窗口允许半个当前数据源采样间隔的时间容差（OKX 1 秒、OCR 1.5 秒），避免 119.99 秒样本被误判。相邻成功读价超过 30 秒时重建窗口并重置情绪；同一 API 品种内部的短暂请求失败恢复可保留历史。

自动表情至少保持 10 秒；普通幅度突变也遵守保持时间，首次恐慌、跌破止损或新账户风险可立即切换。同一心情不定时轮播，实际换脸才说普通台词和播放相关音效。手动点击可立即在当前心情图片池换图，并重新开始 10 秒保持；单图池不会重复说话。FX 中气泡消失不重置表情。初始数据不足时点击不会猜测心情。

情绪值按同方向心情持续时间累积，20 秒满档（-10～+10）；反向或横盘重计，不因加快采样而加速。高情绪台词还要求完整 120 秒窗口与当前方向一致且幅度超过 0.04%。长窗口未满时仍可正常换表情，只使用普通台词。

“FX设置…”可填写止损价，留空关闭。每次从上方跌破时只喊一次“该止损了……真的要止损吗？”，回到止损价上方后重新布防。盯盘满 1 小时，按保持时间安排第 4 张和“休息一下吧”，每次 FX 会话一次。止损、休息及关闭总结是一次性的事件提示；即使已经是第 4 张，休息提醒仍会说一次。

取消勾选后回默认图，用一句话总结首次 / 最后一次成功读价之间的涨跌幅。这是本程序的盯盘记录，不是交易所日涨跌幅。截图每次开启时重新框选，并重置对应区域的当天基准；OKX 同品种同一天重复开关或重启仍沿用基准，避免把不同品种的价格混在一起。

### 欧易 OKX API

选择该数据源后，在“FX设置…”先选现货、永续或 XPERP，再搜索 / 选择交易对，例如 `BTC-USDT`；永续自动补为 `BTC-USDT-SWAP`。XPERP 从 `instType=FUTURES` 列表中只保留含 `_UM_XPERP` 的有效品种，不列出普通交割合约和期权；选择或手动输入完整 ID，例如 `IRYS-USD_UM_XPERP-310530`，保留日期后缀，不追加 `-SWAP`。列表来自 OKX 公共 instruments 接口，无需密钥，后台加载并按市场 / 模拟盘缓存一小时；刷新可重新获取，失败时可用缓存或手动输入完整交易对。截图数据源下该选择禁用，仍只读取框选价格。再勾选“FX启动！”，默认每 2 秒调度读取公共 ticker 的最新成交价，沿用相同的 30 / 120 秒双窗口、涨跌阈值、10 秒保持及点击逻辑，不需要先框选区域。

“表情灵敏度”可选外汇股票（0.05 / 0.20 / 2%）、默认（0.08 / 0.30 / 3%）、加密货币（0.15 / 0.60 / 5%）或自定义，三项依次为横盘、强波动、恐慌跌幅。自定义显示三个百分比输入框，必须为有限正数且严格递增，不合法不能保存。“恢复默认”只恢复灵敏度。退出横盘阈值为横盘进入值的 50%，强波动退出值为强波动进入值的 2/3；若后者不高于横盘进入值，则取两个进入值的中点。

灵敏度保存后立即应用，保留价格窗口和会话计时，清除旧阈值下的候选心情与连续确认计数；普通变化仍需两个新的有效采样确认，修改设置不算采样。三个自定义输入最多显示、输入和保存两位小数，并省略末尾多余的零（例如 `0.08 %`、`0.3 %`）；自动计算的退出阈值保留计算精度。新的恐慌阈值可立即检查已有涨跌幅。旧 JSON 数值优先，自动匹配预设；自定义退出阈值在未编辑灵敏度前保留。`fx.sensitivity_preset` 只记录预设，`okx.inst_type` 由 `inst_id` 兼容推断：`-SWAP` 为永续，有效 `_UM_XPERP` ID 为 `FUTURES`；缺少或过时的类型字段不改变原交易对。

设置中的五个数值框和音量滑块不接受滚轮改值，即使控件已有焦点；滚轮可用于滚动页面，仍可键盘操作。底部“恢复数值默认”恢复默认灵敏度、30% 音量、将持仓浮亏 / 今日观测权益亏损提醒线均设为 3%，并清空手填止损价；点击保存后保留，取消则放弃。交易对、模拟盘选项和密钥保持不变。

保存新交易对或切换现货 / 永续 / XPERP、模拟盘 / 实盘时清空价格窗口和情绪，拒收旧请求，重新预热，保留盯盘与休息计时；手填的绝对止损价清空并提示，账户百分比提醒线保留。若当前处于 API 回退的截图识别，修改备用 API 品种不会清空正在用的 OCR 窗口；恢复 API 时仍按跨源规则重新预热。

行情和账户使用独立后台任务及定时器；账户默认每 5 秒调度，慢账户请求不会拖住公共行情。任一路径上次请求未完成就跳过本轮，不并发堆积；例如行情请求耗时 3 秒时，实际成功间隔可能约 4 秒。账户错误只延迟账户更新，不触发行情回退。

账户读取是可选项：在设置中填写 API Key、Secret Key 和 Passphrase 三项，只读权限才启用。先通过 `/api/v5/account/config` 检查权限；若含交易或提币权限，会弹出“建议改成只读”，禁用账户读取但保留公共行情。模拟盘勾选后添加 `x-simulated-trading: 1`，应使用对应模拟盘密钥。

- `/api/v5/account/positions`：读取所有非零持仓的 `uplRatio`，任一持仓浮亏率达到 3% 时进入恐慌，并提醒“该止损了……真的要止损吗？”。这是接口提供的持仓收益率，不是价格跌幅；回到阈值以内后重新布防。账户读取启用后替代手填止损价。
- `/api/v5/account/balance`：读取 `totalEq`，用 UTC+8 当天首次成功读取的权益作基准。下降达到 3% 时使用哭泣表情 8 / 14，并提醒今天停手，每账户每天提醒一次。显示名称是**本程序今日观测值**；转入转出、交易及浮盈亏都会影响权益，因此它不是交易所完整当日盈亏。首次读取之前的盈亏不计入。基准跨重启保留，模拟盘和实盘分开。
- 两个阈值都可在设置或 JSON 的 `okx.position_stop_loss_percent`、`okx.daily_loss_percent` 修改，单位为百分数数值。首次进入持仓风险或当日亏损风险可立即换脸，重复账户采样不重复提醒。

OKX 连续读取失败 3 次才回退截图识别，并提示“欸？行情连不上了……”；成功读取会清零失败计数。回退后每 30 秒尝试一次 OKX，成功后自动切回；没有有效截图区域也继续重连，可在 FX设置中框选同一品种的价格。单次请求至少允许 5 秒，旧 JSON 中小于 5 的超时值在运行时按 5 秒处理，配置文件不改写。

截图和 API 之间的任何切换（菜单切源、API 失败回退、自动恢复）都会清空价格窗口和情绪，重新满足至少 10 秒及 4 个有效价格的预热条件；截图无法确认品种，即使价格接近也不共用窗口。同一 API 交易对、同一实盘 / 模拟盘内的重试或重新连接才保留历史；修改交易对或实盘 / 模拟盘也清空窗口。切源保留表情保持时间和休息计时。用户主动选截图模式后停止 API 重试。行情日统计按截图区域、OKX 交易对和模拟盘 / 实盘分别保存；直接修改注册表 `fx/region` 也会识别新区域。同一截图区域读价相对当天基准或上次有效价格偏离超过 50% 时，重置当天基准和不兼容的价格窗口，防止换品种混算。每次开启截图 FX 时的框选会清空旧、新区域的当天基准，即使框到相同位置。旧的全品种 `fx/day` 基准不再使用。

### 隐私与识别范围

截图只在本地内存处理，不保存、不上传，没有云端调用或模型下载。持久化区域、止损价、位置、大小、静音偏好、当天首尾有效价格和账户观测权益基准。程序自身尽量从截图排除；无法排除且遮住区域则跳过。菜单或设置打开时暂停采样。

密钥仅存 exe 旁的 `okx.local.json`，不会写入 `kurumi.json`、日志或打包素材，不会传给任何模型。启用账户读取时只通过 HTTPS 发往 OKX 的认证接口。此文件是本机明文配置，请勿随程序分享；设置中清空三项并保存即可移除凭据内容。程序仅允许四个固定 GET 接口（ticker、config、positions、balance），无下单、撤单或提币接口，也不跟随 HTTP 重定向。

OCR 是本地读屏，仍可能误读数字或小数点；请让选定价格保持清晰可见。遮挡、窗口移位、闪烁或特殊字体可能导致跳过。右键菜单和托盘显示最后价格、滚动涨跌幅、心情和情绪值，可随时停止或重新框选。

## 配置

`kurumi.json` 的 `default`、`duration`、`lines` 保留原含义。顶层 `data_source` 为 `ocr` 或 `okx`。`okx` 配置：

```json
"okx": {
  "inst_id": "BTC-USDT",
  "simulated": false,
  "position_stop_loss_percent": 3.0,
  "daily_loss_percent": 3.0,
  "timeout_seconds": 5.0
}
```

密钥不填在该对象中。新增 `fx`：

| 字段 | 默认值 / 含义 |
| --- | --- |
| interval_ms / okx_interval_ms / account_interval_ms | 3000 / 2000 / 5000，OCR / 公共行情 / 账户调度毫秒 |
| fast_window_seconds / window_seconds | 30 / 120，短窗口 / 长窗口秒 |
| warmup_seconds / warmup_samples | 10 / 4，短预热最小跨度及有效价格数 |
| confirm_samples | 2，普通心情连续确认次数 |
| hold_seconds | 10，普通自动换脸最短保持秒 |
| flat_percent / strong_percent / panic_drop_percent | 0.08 / 0.30 / 3，进入阈值，百分数数值 |
| flat_exit_percent / strong_exit_percent | 0.04 / 0.20，退出阈值，百分数数值 |
| emotion_seconds | 20，同方向心情满情绪的秒数；高档另需长窗口同向 |
| flat_sleep_seconds / rest_after_seconds | 300 / 3600，连续横盘 / 会话休息秒 |
| max_sample_gap_seconds | 30，成功读价间断超过此值重新预热 |
| ocr_confidence | 0.90，OCR 最低置信度 |
| exclude_from_capture | true，FX 开启时将桌宠从屏幕截图中排除；false 可供远程测试截图核对表情 |
| debug_log | false，开启后记录采样及表情 / 音效诊断日志 |
| stop_loss | null，初始止损价；界面保存的个人设置优先，界面留空表示关闭 |
| poses | 各心情的图片编号数组 |
| lines_intense | 图片 1～14 的高情绪台词数组；普通档使用顶层 lines |

旧字段 `emotion_streak`、`immediate_change_percent` 保留时不再参与新逻辑。

改 JSON 后重启生效。旧 JSON 没有 fx 也能用默认规则；FX 字段不合法时仅回退 FX 默认规则并记日志。

### 远程测试与采样日志

在**已有的 `fx` 对象内部**加入以下字段，保留其他配置；本次响应速度更新仅迁移上述采样、窗口和防抖参数。省略字段时分别按 `true` / `false` 处理。

```json
"exclude_from_capture": false,
"debug_log": true
```

保存并退出重启。`exclude_from_capture: false` 会清除 Windows 截图排除标记，允许远程截图看到桌宠；关闭 FX 时也会清除。为避免误读，若桌宠遮住选定价格区域，截图采样仍跳过并记录 `pet_occludes_region`，请把她拖到区域外。该开关不改变截图不保存、不上传的行为。

诊断追加到 `%LOCALAPPDATA%\KurumiPet\kurumi.log`，每行 `FX_DEBUG` 后是 JSON。关闭 `debug_log` 时不输出这些诊断行，原有警告 / 错误日志不变。`time` 为带时区和毫秒的记录时间；`sample_time` 是采样尝试开始时间，`monotonic_s` 可计算真实间隔，`elapsed_ms` 是本次采样处理耗时。

- `event: sample`：每次采样成功或跳过均记录 `sample_id`、来源 `source`、`price`、短窗口涨跌百分数 `percent`、长窗口涨跌百分数 `long_percent`、`fast_window_seconds` / `window_seconds`、实际短窗口跨度 `span_seconds`、未满短窗口标记 `warming`、心情 `mood`、台词情绪档 `tier`（0 / 1）、`skipped` 和 `reason`。未读到价格为 null；未达到短预热时 `percent` 为 null；预热后使用实际跨度涨幅，长窗口未满时 `long_percent` 为 null。读取失败不会复用上一笔价格冒充本次价格。
- 跳过原因：`busy` 上次未完成、`dragging` 拖动中、`menu_open` 菜单打开、`settings_open` 设置 / 弹窗打开、`invalid_region` 区域失效、`pet_occludes_region` 桌宠遮挡价格、`capture_error` / `capture_empty` 截图失败 / 空图、`ocr_error` 模型运行失败、`ocr_unreadable` 无可信单个价格、`okx_error_retry` API 本次失败等待下次采样、`okx_error_fallback` 连续失败达到门槛并回退、`okx_retry_failed` 回退后的 API 探测失败、`region_changed` 识别期间区域已更改、`stale_result` 旧会话返回值丢弃。成功为 `accepted`。API 失败行含 `consecutive_failures`，回退及探测失败行另含 `retry_seconds`；自动恢复另记 `okx_recovered`，价格量级突变重置另记 `day_baseline_reset`。
- `event: pose`：只在实际换图时记录 `pose_id`、`from_pose`、`pose`、心情与档位、`audio_group`（good / bad）、具体 `sound` 文件名主体及 `audio_status`。静音、零音量、无对应音效分别是 `muted`、`volume_zero`、`no_effect`，`audio_played` 为 false。
- 异步音效先记 `queued`，此时 `audio_played` 为 null，表示尚未确认播放；随后另记 `event: audio_result`，通过同一 `pose_id` 对应，`played` / true 表示 Windows 播放命令成功，`cancelled`、`failed`、`closed` / false 表示被新点击或静音取消、播放失败、播放器已关闭。该结果表示程序已启动播放，不代表 Windows 系统音量或输出设备一定可听。普通模式点击不产生 FX 诊断。

日志只记这些明确的诊断字段，不记录截图、OCR 原文、账户响应、认证请求头或密钥。

## 开发与构建

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
.venv\Scripts\python.exe tests\test_pet.py
.venv\Scripts\python.exe tests\test_fx.py
.venv\Scripts\python.exe tests\test_audio.py
.venv\Scripts\python.exe tests\test_okx.py
.venv\Scripts\python.exe tests\test_debug.py
.venv\Scripts\python.exe main.py --self-test build\source.json
```

`build.ps1` 创建 venv、装固定版本依赖、准备 PNG、构建 exe 并复制可替换素材和说明。原始 JPG 保留；`prepare_assets.py` 移除与边缘连通的近白底，已有 PNG 默认不覆盖。针对原始半身贴纸未封闭的裙摆及第 9 张高光缺口，先在分割蒙版中封闭边界，保留浅色裙子，避免背景填充侵入衣服。`source_trims.json` 记录边界路径及原图 SHA-256，仅匹配原图时应用；`--rebuild` 可从原 JPG 重新生成 PNG。原始 JPG 自带模糊不会被高 DPI 渲染凭空恢复；可换更精细透明图。

`Kurumi.spec` 内置一个约 11MB 的 OCR 识别模型和 CPU 运行库，仅收集使用的 Qt 模块。过滤 PATH 中其他软件带来的 ICU DLL，使用 Windows 内置 ICU。`--self-test` 只用合成价格和模拟 OKX 公共响应验证 OCR、逻辑和依赖，输出报告 / 桌宠预览，不截取真实屏幕、不读取密钥、不请求真实账户。构建只收集明确列出的公开素材，不打包 `okx.local.json`。

位置、区域、止损、静音偏好、当天首尾价格及账户观测权益基准存于 `HKCU\Software\KurumiPet\DesktopPet`。数据源、交易对和 OKX 风险阈值存于 exe 旁 `kurumi.json`；三项凭据单独存于 `okx.local.json`。开机自启是当前用户 Run 的 `KurumiDesktopPet` 项，仅主动勾选时写入。日志 `%LOCALAPPDATA%\KurumiPet\kurumi.log`，不记录截图、OCR 原始文本、密钥、认证请求头或接口响应。

## 音效

仅包含用户提供的 `mp3/` 中六份已统一音量的文件，复制到 `assets/sfx/`：

- 普通模式左键换表情：`click_1.mp3`。
- FX 切到上涨表情（1、2、5）：`good_1.mp3` / `good_2.mp3` 随机。
- FX 切到下跌表情（3、7、8、9、11、13、14）：`bad_1.mp3` / `bad_2.mp3` / `bad_3.mp3` 随机。

FX 只在图片编号实际改变时触发，横盘、犯困、休息、启动 / 停止和未换脸的轮询不响。
FX 手动点击换脸也按上涨 / 下跌表情使用对应音效；单图心情不重复播放。
新音效会打断上一段，避免连续点击叠音。音频打开、解码及播放均在专用后台线程，缓存已打开的音效，快速点击只保留最新请求，避免双击时界面卡住。右键“静音”停止播放并取消排队音效，选择记住下次启动。

默认音量降至 30%，`kurumi.json` 对应 `"sound": {"volume": 0.3}`，范围 `0.0～1.0`，0 表示无声。FX 设置中灵敏度下方提供 0–100% 音量滑块，拖动立即调整正在播放及之后播放的音效，不重播音效；保存后写入 JSON，下次启动沿用，取消则恢复打开设置前的音量。滑块不响应鼠标滚轮，静音开关保持独立，不会因调音量自动解除。
这是桌宠音量，不修改 Windows 系统音量。旧 JSON 缺少此项或值非法时使用新默认 0.3；已有合法音量保留，不强制覆盖。未触碰滑块时保留原有数值精度和缺省字段；“恢复数值默认”可明确恢复 30%。手动编辑 JSON 后重启生效。构建时单独生成公开内置默认配置，不改开发目录或 dist 中已有的配置文件。
exe 旁 `assets/sfx/` 可覆盖内置同名 MP3，缺失或不能解码时尝试内置音效。
使用 Windows 原生 MP3 播放，不增加额外多媒体框架依赖。来源记录原样保存在项目及发布目录的 `LICENSES.txt`，exe 内也保留一份。
